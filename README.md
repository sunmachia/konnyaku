# こんにゃくで、群馬をもっと盛り上げる。 | 樹徳高等学校 2SS1班

群馬の名産こんにゃくを使って農家の方を間接的に支援し、群馬を盛り上げる探究プロジェクトの公式サイトです。

- 公開サイト: Render Static Site
- 技術: HTML + Tailwind CDN + バニラJavaScript
- ビルド不要の静的サイト
- 現在の商品候補: こんにゃく粉入りクレープ（仮）。配合5%または10%が有力

## 開発

```bash
python3 -m http.server 8000 --directory .
# http://localhost:8000
```

## デプロイ（Render）

- Build Command: （空欄）
- Publish Directory: `.`

## 構成

- `index.html` — サイト本体（「商品紹介」「私たちについて」の2タブ）
- `404.html` — ページが見つからないときの案内
- `robots.txt` — 検索エンジン向け設定

## 更新するとき

- **活動記録**: `index.html` の「活動記録」セクションに `<li>` を追加し、活動記録とフッターの最終更新日を書き換える
- **フェーズ**: ヘッダー、ヒーロー、商品紹介、活動記録、私たちについての「フェーズ0」表記を揃えて更新する
- **商品情報**: 商品化を検討中。商品名・価格・カロリー・販売方法はComing soon。クレープの配合実験の結果は活動記録に反映する
- **SNS**: アカウントが決まったら「今後の予定」にリンクを追加する
- **OGP**: 公開URLが決まったら `og:url` と `og:image` を追加する（現在は画像なし）

## メモ

- 写真は意図的に使用していません。写真が用意できたら、商品紹介セクションに追加できます。
- Tailwind CDN はビルド不要で編集しやすい反面、本番では事前コンパイル版より少し重くなります。公開規模が大きくなったら Tailwind CLI でのCSS生成も検討してください。
- タブは `#product` / `#project` のURLで直接開けます。`#log` などセクションへのリンクも、対応するタブへ自動で切り替わります。
