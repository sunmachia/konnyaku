# こんにゃくクレーププロジェクト

樹徳高等学校2SS1班が、群馬のこんにゃくを使った新しいクレープを研究・紹介するための静的サイトです。

## サイト構成

- `index.html` — 商品紹介ページ（学校公式サイトへ移設できるよう独立構成）
- `research.html` — 探究活動紹介ページ
- `survey.html` — 食べた人向け匿名アンケート
- `styles.css` — 3ページ共通のデザイン・アニメーション
- `site.js` — メニュー開閉、スクロール表示、アンケート完了処理
- `404.html` — ページが見つからない場合の案内

## デザイン

ファストフードブランドの親しみやすさと、クレープのおしゃれさを組み合わせたデザイン。トマトレッド×マスタードイエローを基調に、アニメーションを各所に配置しています。

## 公開

Render Static Siteで公開する場合、Build Commandを空欄、Publish Directoryを `.` に設定します。商品ページだけを学校公式サイトへ置く場合は、`index.html` と `styles.css` を移設し、リンク先を差し替えます。

## アンケートについて

`survey.html` の送信処理は現在プレビュー動作です。Google Apps ScriptのWebアプリURLを接続することで、実際の回答保存が有効になります。接続方法はGAS側の設定後に案内します。
