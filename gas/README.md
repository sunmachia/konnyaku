# アンケート送信API（Google Apps Script）

`survey/index.html` のアンケート回答を、Googleスプレッドシートに保存するためのGASです。

## しくみ

1. QRコード → Renderの `/survey/`
2. 回答者が「送信する」をタップ
3. 画面に見えないフォームから、GASのWebアプリへPOST
4. GASがスプレッドシートに1行追加
5. GASが `parent.postMessage` で「保存OK」をアンケート画面へ返す
6. アンケート画面に「ありがとうございました！」を表示

GASのWebアプリはCORSの制約があるため、`fetch`ではなく**隠しiframeへのフォームPOST**を使っています。

## 設置手順

1. 回答を保存するGoogleスプレッドシートを新規作成する
2. スプレッドシートの「拡張機能」→「Apps Script」を開く
3. `Code.gs` の内容を貼り付けて保存する
4. エディタの関数選択で `setup` を選び、実行する
   - 初回は権限の承認を求められます
   - `responses` シートと見出し行が作成されます
5. 「デプロイ」→「新しいデプロイ」→「ウェブアプリ」
   - 説明: `こんにゃくクレープ アンケート`
   - 実行ユーザー: `自分`
   - アクセスできるユーザー: `全員`
6. 発行されたWebアプリURLをコピーする
7. `survey/index.html` の次の行に貼り付ける

```js
var GAS_ENDPOINT = 'https://script.google.com/macros/s/xxxxxxxx/exec';
```

8. アンケート画面を開き、テスト回答を1件送信する
9. スプレッドシートに1行追加されていれば成功

## テスト方法

- **GAS単体**: エディタで `testDoPost` を実行 → `responses` にテスト行が1行追加される
- **画面から**: アンケートを最後まで回答して送信 → スプレッドシートを確認
- **二重送信**: 同じ画面で再送しても、`requestId` が同じ間は二重保存されません（6時間キャッシュ）

テスト行は確認後に削除してください。

## 注意すること

### アカウントの所有者

スクリプトとスプレッドシートは、**学校または先生のGoogleアカウント**で作成してください。生徒の個人アカウントだと、卒業後に停止・削除される可能性があります。

### 学校のGoogle Workspaceの制限

学校の管理設定によっては、Webアプリを「全員（匿名）」で公開できない場合があります。先に小さなテストで確認してください。NGの場合は、以下のどれかを検討します。

- 先生・管理者に公開設定を緩めてもらう
- GASのHTML Serviceでアンケート画面ごと配信する（CORS不要）
- 別の保存先（Supabase、Googleフォームなど）に切り替える

### スパム対策

WebアプリのURLを知っていれば誰でもPOSTできます。現在は次の対策を入れています。

- 画面に見えない `website` 項目（ハニーポット）
- 必須項目と値の範囲チェック
- 店舗ID・商品IDの文字種チェック
- 同一 `requestId` の二重保存防止
- コメントは300文字まで

本格的な認証はしていません。学校の公開アンケートとして、いたずらが多発する場合は管理者に相談してください。

### 個人情報

- 氏名・連絡先・住所などは入力させない
- 自由記述に個人情報が入る可能性があるため、画面に注意書きを出している
- スプレッドシートは公開せず、関係者だけに共有する
- 回答の保存期間・削除ルールを先生と決めておく

### 回答数の上限

GASには1日の実行回数などの上限があります。小規模な店舗アンケートなら通常は問題ありませんが、大量回答が見込まれる場合は事前に確認してください。回答が増えたら、定期的にCSVで退避するのがおすすめです。

## シートの列

| 列 | 内容 |
| --- | --- |
| A | 受信日時（GASサーバー時刻） |
| B | 回答ID（UUID） |
| C | 店舗ID（QRの `?store=`） |
| D | 商品ID（QRの `?product=`） |
| E | 総合評価（1〜5） |
| F | 味（1〜5） |
| G | 食感（1〜5） |
| H | 見た目（1〜5） |
| I | また食べたい（yes / maybe / no） |
| J | ひとこと（任意・300文字まで） |
| K | アンケート版 |
| L | ページURL |

## 店舗ごとのQRコード

QRコードのURLに `?store=kiryu` のように店舗IDを付けると、回答が店舗別に集計できます。

```text
https://<RenderのURL>/survey/?store=kiryu
https://<RenderのURL>/survey/?store=kiryu&product=konnyaku-crepe
```

店舗IDは英数字・ハイフン・アンダースコアだけにしてください（日本語は保存できません）。
